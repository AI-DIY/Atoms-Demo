## 1. 产品与体验入口

**Atoms Demo** 是一个可运行的 Atoms 风格智能体工作台：从首页描述想法或选择资源创意，进入团队对话与应用编辑器，通过真实 AI 生成应用、操作预览、对话迭代、源码修改、历史恢复和公开分享。本轮按 Atoms 实际登录首页、资源页和项目工作区重新调整了视觉与导航。

- 在线 Demo：<http://atoms.ai-diy.me>

- GitHub 源码：<https://github.com/AI-DIY/Atoms-Demo>
- 固定版本源码：<https://github.com/AI-DIY/Atoms-Demo/tree/2.0.0>
- 本笔试文档的公开链接：<https://github.com/AI-DIY/Atoms-Demo/blob/2.0.0/全栈岗位笔试——赵心语/README.md>
- 补充说明：[实现、完成度、AI Coding 使用与扩展计划](../补充说明/全栈岗位笔试——赵心语.md)

## 3. 建议评审流程（约 5–10 分钟）

1. 打开 Demo，查看首页；进入“资源”，尝试发现/模板、分类、搜索和收藏，打开详情并点击“使用此创意”。
2. 返回首页后可调整已填入的需求和视觉风格。也可自行描述：“创建摄影预约与报价工具，支持客户姓名、预约日期、服务套餐、预计报价、添加和删除预约，使用清晰的中文界面。”
3. 点击向上箭头“开始构建”；未登录时弹出账户窗口，点击“还没有账户？注册”，使用测试邮箱和至少 8 位密码注册。输入保留，随后自动进入工作区；顶部应显示“真实 AI · Responses API”。
4. 等待规划、构建、验收完成。展开“查看团队交付文档”，查看需求和架构产物；右侧出现生成应用后，实际添加一条记录。
5. 等待“应用数据已保存”，刷新整个页面，验证记录保留。点击“移动端预览”，检查窄屏布局。
6. 输入一条具体修改，例如“保留现有预约数据，把主按钮改为蓝色，并改善空状态提示”。完成后应产生 V2。
7. 输入 `@研究员 分析这个工具最值得验证的用户需求`，查看独立专家响应。
8. 打开“代码”，修改一个页面标题，点击“保存新版本”。确认新版本生效且业务记录保留。再打开“版本”，选择 V1；后续版本仍保留，业务记录不回滚。
9. 点击“下载 HTML”获得可独立打开的代码文件。点击“发布”→“确认公开发布”，用无痕窗口打开公开链接。
10. 在公开页面添加记录：访客数据保存在访客浏览器，不会暴露作者数据。返回工作区取消发布，原公开链接应返回 404。
11. 点击“返回我的项目”，尝试搜索、排序、列表视图和重命名，再新建第二个项目。从项目页重新打开第一个，验证消息、版本和记录仍存在；手机端通过顶部“对话/预览”切换面板。

真实模型耗时受服务提供方影响；失败会保留既有版本并显示重试入口。按钮中的“验收”表示结构、大小、内容标记和安全清理检查，不替代人工或浏览器功能验证。
